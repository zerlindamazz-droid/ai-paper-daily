🎯 让AI智能体"脚手架"直接参与强化学习训练，大幅提升代码能力

🗣️ 一句话比喻 · Plain-English Analogy就像培训一个赛车手，以前只在游戏模拟器里练习，然后直接上真实赛道比赛——当然容易翻车。Agent Lightning改为直接在真实赛道上训练，弯道、天气、维修站一应俱全。AI在真实"战场"上学习，学的就是它真正要做的事，效果自然天差地别。Imagine training a race car driver only in a video game simulator, then expecting them to win a real Formula 1 race. 维度 中文 English
❓ 待解决
的问题		 现代AI智能体并不是单独工作的——它们依赖一个叫做"脚手架"（harness）的外部系统来管理工具、记忆和任务流程。但现有的AI训练方法把这个脚手架当作透明的，训练时完全忽略它。这种脱节导致训练不稳定、效果差，尤其对于写代码、搜索网页这类复杂任务影响更大。 Modern AI agents don't work alone — they rely on a surrounding "harness" (like a scaffold) that manages tools, memory, and task flow. But existing AI training methods treat this harness as invisible, training the model in isolation without accounting for the real environment the agent will actually work in. This mismatch makes training unstable and less effective, especially for complex tasks like writing code or browsing the web.
💡 解决
的亮点		 • 提出"驾驭式智能体RL"新范式：让真实部署时的脚手架直接参与训练，而不只是推理时用。 • 解耦架构设计：任意智能体框架都能通过LLM端点代理接入RL训练，无需改写智能体代码。 • 系统性解决了5大训练难题：重新分词、样本合并、优势函数计算、损失归一化、后端调度。 • 代码极简（约3500行），完全开源，附完整可复现训练脚本。 • Novel "harnessed agentic RL" paradigm: the real-world agent scaffold (harness) directly participates in training, not just deployment. • Disaggregated architecture: any agent framework can plug into RL training via a simple LLM endpoint proxy — no need to rewrite the agent. • Tackles five tricky training problems (retokenization, sample merging, advantage calculation, loss normalization, backend scheduling) that nobody had systematically addressed before. • Tiny codebase (~3,500 lines) that's easy to study and reproduce, with full open-source training scripts.
🧪 实验
内容		 研究团队在三类智能体上测试了框架：指令跟随、网页搜索和代码编写。重点是代码智能体的完整可复现流程，评估基准为SWE-bench Verified——一个让AI修复真实GitHub软件Bug的权威测试集。仅使用6000条训练样本和普通算力，对Qwen3-32B和Qwen2.5-9B模型进行训练，并与未经微调的基线模型对比。 The researchers tested their framework on three types of agents: instruction-following agents, web search agents, and coding agents. The main focus was a full reproducible pipeline for coding agents, evaluated on SWE-bench Verified — a widely used benchmark where AI must fix real GitHub software bugs. They used only 6,000 training examples and modest hardware, training the Qwen3-32B and Qwen2.5-9B models and comparing against the untuned baselines.

The framework also demonstrated stable training curves and reproducible results across instruction-following and search agent tasks, with ablation studies showing each of the five technical fixes contributes meaningfully to the final performance.
🏁 结论 Agent Lightning v1.0证明了：在真实运行环境（脚手架）中训练AI智能体，而非在人工模拟器中训练，能大幅提升性能——仅用少量数据和算力就在难度较高的代码基准上提升了14.6个百分点。同时提供了一个开放、可复现的框架供研究社区使用。 Agent Lightning v1.0 proves that training AI agents inside their real operating environment (the harness) — rather than in an artificial simulator — leads to dramatically better performance, achieving a 14.6-point boost on a hard coding benchmark with minimal data and compute. ⚙️ Method · 方法详解

想象一下：不是在模拟厨房里训练厨师，而是直接在真实餐厅里训练。Agent Lightning的核心是一个轻量级"代理层"，架在智能体真实运行环境和RL训练引擎之间。脚手架（负责管理工具和上下文的外层系统）像正常部署时一样运行，而代理层悄悄记录智能体每次"提问"和模型每次"回答"。这些记录随后被打包传给RL训练器，训练器根据智能体的实际表现来调整模型。此外，论文系统解决了5个具体技术难题，包括多步对话中如何正确计数token、如何公平分配长任务的功劳等。 Think of it like this: instead of training a chef in a kitchen simulator, Agent Lightning trains the chef in the actual restaurant kitchen — pots, pans, waiters and all. The key trick is a lightweight "proxy" that sits between the agent's real operating environment and the RL training engine. The harness (the scaffold managing tools and context) runs as it normally would during deployment, while the proxy secretly records every question the agent asks and every answer the model gives. These recorded conversations are then packaged up and fed into the RL trainer, which adjusts the model based on how well the agent actually performed. Five specific technical challenges (like how to count tokens correctly across multi-step conversations, and how to fairly assign credit for long task sequences) are each addressed with concrete solutions and ablation studies.

📐 Key Formulas · 关键公式

\[\mathcal{L}_{\text{RL}} = -\mathbb{E}_{(s,a) \sim \pi_{\theta_{\text{old}}}} \left[ \min\left( r_t(\theta) \hat{A}_t,\ \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t \right) \right]\]
💡 PPO裁剪目标函数：衡量新策略与旧策略的差异，并通过裁剪防止更新步伐过大，保证训练稳定。$\hat{A}_t$是优势估计，衡量某个动作比平均水平好多少。 The PPO clipped objective: it measures how much the new policy differs from the old one and clips extreme updates to keep training stable. $\hat{A}_t$ (advantage) measures how much better a given action was compared to average.

🌟 Why It Matters · 为什么重要

这项研究弥合了AI智能体"训练方式"与"实际工作方式"之间的巨大鸿沟，让用于写代码、网页搜索和复杂任务的AI助手变得更加强大。同时，开源的简洁框架也让小团队能用较少资源实现以前需要大量计算才能达到的效果，推动了领域民主化。 This research closes a major gap between how AI agents are trained and how they actually work in the real world, making AI assistants for coding, search, and complex tasks significantly more capable. By releasing a simple, reproducible framework, it also democratizes advanced agent training — letting smaller teams achieve results that previously required huge resources.

Diffusion image models follow predictable scaling laws but need 10× more data than language models to train optimally.
🗣️ 一句话比喻 · Plain-English Analogy就像找到烤蛋糕的完美配方一样：厨师们（AI研究者）一直有一份烤面包（语言模型）的好配方，但从没人验证同样的面粉与水的比例是否适用于蛋糕（图像模型）。这篇论文做了成千上万次小批量试烤，发现蛋糕其实需要10倍的水——而且多加水基本不会毁掉蛋糕，所以拿不准的时候，多加水就对了！Think of it like figuring out the perfect recipe for baking a cake: for years, chefs (AI researchers) had a great recipe for bread (language models), but nobody had tested whether the same flour-to-water ratio works for cakes (image models). ❓ 待解决
的问题		 训练AI图像生成器时，研究人员没有一个可靠的"配方"来决定模型应该有多大、需要多少训练数据。如果把有限的算力预算用错地方——比如做了个超大模型，却只给它喂很少的数据——可能白白浪费数百万美元。指导语言模型（如GPT）训练的"缩放法则"从未在图像生成AI上被系统验证，让从业者只能靠猜。 When building powerful AI image generators, researchers don't have a reliable recipe for deciding how big to make the model or how much data to train it on. Spending your compute budget the wrong way — say, making a giant model but feeding it too little data — wastes millions of dollars. The rules that guide language model training (like GPT) hadn't been rigorously tested for image-generating AI, leaving practitioners guessing.
💡 解决
的亮点		 - 首次对文生图扩散模型进行系统性缩放定律研究，算力范围跨越三个数量级。 - 发现图像扩散模型需要约每参数200个图像token的数据量——是著名的Chinchilla语言模型最优配方的10倍。 - 证明扩散模型对"过度训练"（使用超过理论最优量的数据）具有很强的鲁棒性，从业者应该优先选择"更多数据"而非"更大模型"。 - 证明可预测性不只体现在训练损失上，还延伸到图像质量分数、CFG引导设置、表示质量，以及训练曲线形态——这些都收敛到一个通用规律。 - First systematic scaling law study for text-to-image diffusion models, covering three orders of magnitude in compute budget. - Discovered that image diffusion models need ~200 image tokens per parameter — 10× more data than the famous Chinchilla prescription for language models. - Showed that unlike LLMs, diffusion models are very forgiving of "overtraining" (using more data than the theoretical optimum), so practitioners should lean toward more data over bigger models. - Proved that predictability extends beyond training loss to image quality scores, guidance settings, and even the shape of loss curves — which all collapse into a universal pattern.
🧪 实验
内容		 研究人员在10^19到10^22 FLOPs的算力预算范围内训练了Abra模型族（流匹配Transformer），规模显著超过以往图像模型的缩放研究。他们测量了训练损失、生成质量指标（如FID和美学评分）、CFG（无分类器引导）敏感性以及表示质量。他们以著名的语言模型Chinchilla缩放定律作为基线参考，对比了所得出的最优数据与参数比率，并验证了这种缩放规律是否在所有不同评估维度上都成立。 The researchers trained the Abra model family (flow-matching transformers) across compute budgets spanning 10^19 to 10^22 FLOPs — significantly larger than prior scaling studies for image models. They measured training loss, generative quality metrics (like FID and aesthetic scores), CFG (classifier-free guidance) sensitivity, and representation quality. They compared their derived optimal data-to-parameter ratios against the well-known Chinchilla scaling law for language models as a baseline reference, and checked whether the same scaling behavior held across all these diverse evaluation dimensions.
📊 实验
结果		 核心量化发现：扩散图像模型的计算最优训练需要约每参数200个图像token——是语言模型Chinchilla最优比率（约每参数20个token）的10倍。缩放定律在全部研究算力范围（10^19–10^22 FLOPs）内均表现出可预测性。不同模型大小和算力预算下的训练曲线被证明可以收敛到一个统一的通用形式。与语言模型相比，过度训练（在测试预算范围内）对性能的损害极小，使得数据密集型训练成为安全且推荐的策略。可预测性还延伸至生成质量指标和最优CFG值，而不仅仅局限于损失指标。 The key quantitative finding: compute-optimal training for diffusion image models requires approximately 200 image tokens per parameter — 10× higher than the Chinchilla-optimal ratio of ~20 tokens per parameter for LLMs. The scaling laws were found to hold predictably across the full compute range studied (10^19–10^22 FLOPs). Training curves across different model sizes and compute budgets were shown to collapse onto a single universal form. Overtraining (up to the budgets tested) was found to cause minimal performance degradation compared to language models, making data-heavy training a safe and recommended strategy. Predictability extended to generative quality metrics and optimal CFG values, not just loss.
🏁 结论 本文证明了文生图扩散模型和语言模型一样，遵循清晰可预测的缩放规律——但需要约10倍于语言模型的数据量（相对于模型参数量）才能达到最优训练效果。这为AI图像模型开发者提供了一份可靠的科学蓝图，帮助他们合理分配算力预算。 This paper proves that text-to-image diffusion models obey clear, predictable scaling laws — just like language models — but demand roughly 10× more data relative to model size to train optimally. ⚙️ Method · 方法详解

研究团队构建了一系列受控的流匹配Transformer模型（称为Abra），从小到大，并在从10^19到10^22次浮点运算的多个不同算力预算下分别训练。通过仔细测量损失随模型规模和数据量变化的规律，他们拟合出数学"缩放定律"曲线——就像科学家把实验数据拟合到物理公式一样。这样一来，对于任何给定的算力预算，他们无需实际跑昂贵的实验，就能预测出最优的模型大小和数据集大小。他们还将这些预测结果与实际的图像质量指标（而非仅仅是损失数值）进行了验证。 The team built a controlled family of flow-matching transformer models called Abra, ranging from tiny to large, and trained each one at many different compute budgets — from 10^19 to 10^22 floating-point operations. By carefully measuring how training loss changes as you scale up both model size and data, they fitted mathematical "scaling law" curves, just like scientists fitting data to a physical law. This lets them predict, without actually running the expensive experiment, what the optimal model size and dataset size should be for any given compute budget. They then validated these predictions against actual image quality metrics, not just loss numbers.

📐 Key Formulas · 关键公式

\[N^* \propto C^a, \quad D^* \propto C^b\]
💡 最优模型参数量N*和最优数据量D*都随总算力C以幂律形式增长，其中指数a和b描述了在固定算力预算下如何最优地分配模型规模与数据量。 The optimal model size N* and optimal dataset size D* both grow as power laws of the total compute budget C. The exponents a and b tell you exactly how to split your compute budget between making the model bigger vs. feeding it more data.
\[\text{Compute-optimal: } \frac{D^*}{N^*} \approx 200 \text{ tokens/param (images) vs. } \approx 20 \text{ tokens/param (LLMs)}\]
💡 图像扩散模型的计算最优训练需要约每个参数200个图像token，而语言模型（Chinchilla定律）只需约20个token每参数——相差10倍。 For image diffusion models, the sweet spot is training with about 200 image tokens per model parameter — 10 times more data-heavy than the ~20 tokens/parameter sweet spot for language models like GPT.

🌟 Why It Matters · 为什么重要

这项研究为开发AI图像生成器（如DALL·E或Stable Diffusion）的公司提供了一套有科学依据的算力分配公式，可避免数十亿美元的无效训练投入。它还揭示了图像AI和语言AI之间的根本差异，重塑了业界对这两类模型缩放方式的理解。 This research gives companies building AI image generators (like DALL·E or Stable Diffusion) a science-backed formula for how to spend their compute budgets — preventing billions of dollars in wasteful training runs. It also reveals a fundamental difference between image and language AI, reshaping how the field thinks about scaling these two very different types of models.

🧑‍🔬 Junwei Zhou, Zhen Sun, Binyu Li, Jiangyu Zhou et al.

🎯 首个测试AI能否独立完成真实科研任务的评测基准
ASI-Bench is the first benchmark testing whether AI can do real independent scientific research without human hand-holding.
🗣️ 一句话比喻 · Plain-English Analogy就像考驾照：先让AI按GPS一步步导航，再只告诉它目的地，最后只说"去机场"——现在的AI在有详细导航时还凑合，一旦靠自己就迷路了。ASI-Bench就是这场"无GPS驾照考试"，第一次让我们看清AI究竟有多依赖人工指引。Think of it like giving someone a driving test — first with a GPS giving turn-by-turn directions, then with only the destination address, and finally with just a vague goal like "get to the airport." Today's AI aces the GPS version but crashes badly when left to navigate alone — and ASI-Bench is the test that finally proves it.
维度 中文 English
❓ 待解决
的问题		 现在的AI很擅长回答它已经"学过"的问题，就像一个死记硬背的学生，遇到全新问题就束手无策。我们没有好方法来衡量AI是否真的能像科学家那样：探索未知、提出新想法、并自己验证这些想法。现有的AI评测只考"背诵题"，还给了很多人工提示，根本测不出AI真正的独立科研能力。 Today's AI systems are very good at answering questions based on what they've already been taught — like a student who memorizes the textbook but can't handle brand-new problems. We have no good way to measure whether AI can actually do what scientists do: explore unknowns, come up with new ideas, and verify those ideas on its own. Existing AI benchmarks only test whether AI gives correct answers to known questions, often with lots of human hints — they don't test true independent research ability.
💡 解决
的亮点		 • 首个跨11个科学领域、测试AI完整科研项目能力的基准，而非仅回答问题。 • 在同一任务中逐步撤除人类方法指导，精准衡量AI对人工引导的依赖程度。 • 由40余名领域专家耗费31,000+人时构建，经过严格审核、沙盒执行和自动评分，是迄今最真实、最严苛的AI科研评测。 • First benchmark to test AI's ability to do end-to-end, project-level scientific research across 11 domains — not just answer quiz questions. • Progressively removes human guidance within the same task, so we can see exactly how much AI relies on being told what to do. • Built by 40+ domain experts spending 31,000+ human hours, with rigorous review, sandbox execution, and automated scoring — making it the most realistic and demanding AI science benchmark yet.
🧪 实验
内容		 研究者在60个任务、三种引导级别下测试了18种主流AI智能体-模型组合（涵盖推理模型与自主智能体框架）。任务横跨11个科学领域，使用经领域专家验证的自动评分器评估。基准还经过AI辅助审计和沙盒执行测试，确保任务质量与结果可复现性。 The researchers tested 18 state-of-the-art AI agent-model configurations (combinations of AI reasoning models and autonomous agent frameworks) on all 60 tasks across three levels of methodological guidance. Tasks span 11 scientific domains and were evaluated using automated scorers validated by domain experts. The benchmark also underwent AI-assisted auditing and sandbox execution testing to ensure task quality and reproducibility.
📊 实验
结果		 在18种AI智能体-模型组合上，随着人类指导的撤除，平均得分急剧下降：完整方法指导下为50.91分 → 仅告知方法名称时降至29.10分 → 完全无方法提示时仅26.62分。从有充分引导到完全自主，性能下降约48%，表明当前AI系统高度依赖人工引导，独立完成真实科研任务时得分勉强超过25%。 Across 18 AI agent-model configurations, average scores dropped sharply as human guidance was removed: from 50.91 (full methodological guidance) → 29.10 (only method name given) → 26.62 (no method guidance at all). This represents roughly a 48% drop in performance from fully guided to fully autonomous conditions, demonstrating that current AI systems are heavily dependent on human direction and score barely above 25% when left to work independently on real scientific tasks.
🏁 结论 ASI-Bench证明，当前最先进的AI系统在完全自主条件下，真实科研任务得分仅勉强超过26%，揭示了现有AI与真正人工超级智能之间的巨大差距。该基准为领域提供了一个严格、开放的工具，用于追踪AI迈向自主发现新知识的进展。 ASI-Bench proves that today's best AI systems, even with full autonomy, can barely score above 26% on real scientific research tasks — revealing a massive gap between current AI and true artificial superintelligence. The benchmark provides the field with a rigorous, open tool to track progress toward AI that can genuinely discover new knowledge on its own.

⚙️ Method · 方法详解

ASI-Bench包含60个跨越11个科学领域的真实科研任务。每个任务以三种难度呈现给AI：先给出完整的步骤方法指导，再只告诉AI用哪种方法，最后完全不给任何方法提示——AI必须自己想办法。这种"逐步撤除引导"的设计，能精准定位AI在哪个环节开始"掉链子"。所有任务在安全沙盒环境中运行并自动评分，确保结果公平可复现。 ASI-Bench contains 60 real research tasks spanning 11 scientific fields (like biology, chemistry, and computer science). Each task is presented to AI in three levels of difficulty: first with full step-by-step method guidance, then with only the method name given, and finally with no methodological hints at all — the AI must figure out the approach entirely by itself. This "guidance withdrawal" design lets researchers see exactly where AI starts to fall apart. All tasks are run in a secure sandbox environment and scored automatically, ensuring fair and reproducible results.

⚙️ Method · 方法详解

本文围绕Oja算法展开——这是一种经典的"一遍扫数据"流式方法，每来一个新数据点就更新一次对主方向的估计。核心技巧是一个"线性化"思路：将Oja算法复杂的非线性更新步骤近似为更简单的线性步骤，并严格控制这种近似带来的误差。线性化之后，再利用高维高斯近似，证明估计误差即使在高维情形下也近似服从正态分布。最后，设计了一个在线乘数Bootstrap算法，通过对流入数据随机赋权来模拟误差分布，让用户可以实时构建置信区间，无需重新读取历史数据。 The paper uses Oja's algorithm — a classic one-pass streaming method that updates its estimate of the top directions each time a new data point arrives. The key insight is a clever "linearization" trick: they approximate the complex, non-linear updates of Oja's algorithm with simpler linear ones, and rigorously bound how much error this approximation introduces. This linearization then enables a Gaussian approximation — showing that the estimation error behaves like a well-understood bell-curve distribution even in high dimensions. Finally, they design an online multiplier bootstrap that mimics this distribution by randomly re-weighting data as it streams in, letting users build confidence intervals without ever revisiting old data.

📐 Key Formulas · 关键公式

\[U_{t+1} = \text{qr}\!\left(U_t + \frac{\eta_t}{t} x_t x_t^\top U_t\right)\]
💡 Oja算法的核心更新步骤：每来一个新数据点 x_t，就用它微调当前的主方向估计 U_t，学习率 η_t/t 随时间衰减，qr 表示正交化操作保证结果仍是一组正交基。 The core update of Oja's algorithm: each new data point x_t nudges the current subspace estimate U_t by a small step (shrinking learning rate η_t/t), then the result is re-orthogonalized (qr) to keep it a valid set of directions.
\[\sqrt{T}\,\text{vec}(\hat{U}_T - U^*) \xrightarrow{d} \mathcal{N}(0, \Sigma)\]
💡 中心极限定理式结果：经过T步后，估计子空间与真实子空间之差（经过√T缩放）在分布上趋近于均值为零、协方差为Σ的高斯分布，这为构建置信区间提供了理论依据。 A central-limit-theorem-style result: after T steps, the scaled difference between the estimated and true subspace converges in distribution to a Gaussian with mean zero and covariance Σ, enabling valid confidence intervals.
