Alaya-EVOKE: From Linear-Scaling Supervision to Endless World Alaya-EVOKE：从线性扩展监督到无限世界

🧑‍🔬 Yuanyang Yin, Gongxuan Wang, Yifan Zhan, Chuanhao Li et al.

🎯 能无限生成交互式世界视频、内存不爆炸的世界模型
Evoke builds an interactive world model that generates endless, responsive video with bounded memory and fast inference.
🗣️ 一句话比喻 · Plain-English Analogy就像一个拍无限长电影的导演，他不靠自己的脑子记住每一帧画面，而是有一个智能档案柜放在身边——只在需要某个场景时才去翻对应的文件夹。而且他的副导演会用精华集锦加简短摘要来检查前后是否一致，这样无论电影拍多长，导演都不会"忘掉开头"。Think of it like a movie director with a perfect assistant: instead of memorizing every single scene ever filmed, the director keeps a smart filing cabinet outside their head — only pulling out the photos relevant to the current shot. And instead of watching the whole movie to check consistency, the assistant uses a clever highlight reel plus a short summary, so the director never loses the plot — even for a film that never ends.
维度 中文 English
❓ 待解决
的问题		 现有的AI视频世界模型就像一个记忆越来越混乱的人：生成的时间越长，需要记住的内容越多，内存会越撑越大，最终崩溃。而且为了让它响应更快，只能牺牲质量；时间一长，它还会"漂移"——慢慢忘记世界一开始长什么样，生成出前后矛盾的场景。 Existing AI video world models can't run forever — the longer they generate, the more memory they consume, until the system grinds to a halt. On top of that, making them respond quickly (low latency) usually means sacrificing quality, and they tend to "drift" over time — slowly forgetting what the world looked like at the start and producing inconsistent scenes.
💡 解决
的亮点		 • 外部世界状态库：场景几何信息存在一个按摄像机视角索引的外部记忆库中，模型只加载当前视野内的内容，无论会话多长，内存占用始终保持稳定。 • 专为长序列设计的教师模型：不再使用固定的现成教师，而是专门设计了一个能监督超长序列的教师——结合分块注意力、远帧检索和全局线性注意力，计算量只线性增长。 • 抗漂移的学生模型：通过30秒分布匹配训练目标，将长期一致性"灌输"给只需3步推理的快速学生模型，无需分类器引导即可抵抗内容漂移。 • External World State Bank: Scene geometry is stored in an outside memory vault indexed by camera viewpoint, so the model only loads what's currently visible — keeping memory use flat no matter how long the session runs. • Smart Teacher Model: Instead of using a fixed, off-the-shelf teacher to train a fast student model, Evoke designs a custom teacher that can supervise very long sequences using a clever combination of chunked attention, selective long-range frame retrieval, and a compact global memory — all growing only linearly in cost. • Drift-Resistant Student: A 30-second distribution-matching training trick transfers long-horizon consistency to a lightning-fast 3-step student model, making it resistant to content drift without needing extra guidance tricks.
🧪 实验
内容		 团队在WBench、VBench-Long和VBench-2.0等主流交互视频生成基准上评测了Evoke，与当前最优的世界模型方法进行了对比，评估指标涵盖视频质量、长期一致性和交互响应能力。实验在单张NVIDIA H200 GPU上以384×640分辨率运行，以1.5秒为单位逐块生成，模拟开放式连续世界生成场景。 The team evaluated Evoke on standard interactive video generation benchmarks including WBench, VBench-Long, and VBench-2.0. They compared against state-of-the-art world model baselines and measured video quality, long-term consistency, and interactive responsiveness. The model was tested at 384×640 resolution on a single NVIDIA H200 GPU, generating 1.5-second chunks to simulate open-ended, continuous world generation.
📊 实验
结果		 Evoke在WBench上取得最先进水平，在VBench-Long和VBench-2.0上也保持竞争力。作为一个仅需3步推理的超快模型，在单张H200 GPU上以384×640分辨率生成每段1.5秒视频只需2.11秒，具备实时交互潜力。线性扩展教师模型将长序列的内存和计算增长从二次方降低到线性，支持长达30秒序列的监督训练。 Evoke achieves state-of-the-art performance on WBench while remaining competitive on both VBench-Long and VBench-2.0. As a 3-step model (extremely fast inference), it generates each 1.5-second video chunk in just 2.11 seconds on a single H200 GPU at 384×640 resolution — making it practical for real-time interactive applications. The linear-scaling teacher reduces memory and compute growth from quadratic to linear over long sequences, enabling supervision over sequences as long as 30 seconds.
🏁 结论 Evoke证明，通过外置场景状态记忆并重新设计长序列监督训练流程，交互式世界模型可以无限生成高质量视频而不会导致内存爆炸，同时保持足够快的推理速度满足实时交互需求。 Evoke proves that an interactive world model can generate open-ended, high-quality video indefinitely without memory blowup, by externalizing scene state and redesigning the training pipeline for long-horizon consistency — all while staying fast enough for real-time use.

⚙️ Method · 方法详解

这个模型可以理解为两个角色合作：一个"图书管理员"和一个"快手画家"。图书管理员（外部世界状态库）在模型外部按摄像角度整理好3D场景地图，画家只需从对应书架上取当前需要的内容，不用把整个图书馆都装进脑子。教师模型被重新设计成能高效阅读超长"故事"的版本：把相邻视频片段打包处理，偶尔回头看看重要的远帧，同时用一个紧凑的全局摘要概括其他内容，让计算量只线性增长。最后，通过一个30秒的特殊训练练习，把这种长距离一致性"教"给只需3步推理的快速学生模型，让它在生成很远的未来时也不会"忘记"世界的起点。 Think of the model as having two parts: a librarian and a fast artist. The librarian (external world state bank) keeps a tidy, camera-indexed map of the 3D scene outside the main model — so the artist only needs to peek at the relevant shelf instead of carrying the whole library in its head. The teacher model is redesigned to read very long stories efficiently: it groups nearby video chunks together, occasionally glances back at important distant frames, and keeps a compact running summary of everything else — so its memory cost grows slowly (linearly) rather than exploding. Finally, a special 30-second training exercise teaches the fast 3-step student model to mimic the teacher's long-range consistency, so it doesn't "forget" the beginning of the world even when generating far into the future.

\[\text{Memory Cost} = O(L) \text{ (teacher, via linear attention + chunked retrieval)}\]

\[\Delta t_{\text{chunk}} = 2.11\,\text{s} \text{ per } 1.5\,\text{s chunk at } 384 \times 640\]

能持续生成一致、可交互虚拟世界的世界模型，是下一代游戏、机器人仿真和AI智能体"想象未来"的核心基础设施。Evoke高效的内存管理和快速推理架构让这一愿景在现实硬件上变得切实可行。 World models that can generate endless, consistent, interactive environments are a key building block for next-generation gaming, robotics simulation, and AI agents that need to "imagine" futures. Evoke's memory-efficient, fast architecture makes this vision practically deployable on real hardware today.

Training AI Scientists to Replicate Research 训练AI科学家复现研究论文

🧑‍🔬 Damon Falck, Samer Sabri, Anja Surina, Thom Foster et al.

图 Figure · Page 2 of paper

🎯 训练AI自动复现科学论文，超越GPT-5.5与Claude Opus
A 27B AI agent trained to replicate scientific papers, outperforming GPT-5.5 and Claude Opus 4.8.
🗣️ 一句话比喻 · Plain-English Analogy就像培训一个新厨师，不是让他背菜谱，而是让他反复尝试从零复原名厨的招牌菜——尝一口、调整、再试——直到只看菜谱就能做出一模一样的味道。Faraday就是这样学会"复现科学实验"的。Think of it like training a new lab assistant who learns their job not by reading a manual, but by actually trying to recreate famous recipes from scratch — tasting, adjusting, and figuring out the missing steps — until they can reproduce any dish just from reading the recipe card.
维度 中文 English
❓ 待解决
的问题		 复现一篇科学论文——即重新运行别人的实验来验证结论——是科研中最耗时、最复杂的任务之一。原始论文往往缺少细节，研究者需要自己推理、补全空白，就像侦探破案一样。目前的AI模型不擅长这种需要长时间探索、反复假设和验证的研究性任务，尤其是涉及编写并运行真实代码的情况。 Replicating a scientific paper — running someone else's experiments and verifying their results — is one of the hardest and most time-consuming tasks in research. It often requires reading between the lines, filling in gaps the original authors left out, and doing your own mini-investigation. Currently, AI models are not good at this kind of long, exploratory, hypothesis-driven work, especially when it involves writing and running real code over many steps.
💡 解决
的亮点		 • Replica框架：一个可扩展的论文复现任务空间，配有自动生成的评分标准，评分结果与人类专家高度一致，噪声极低。• Faraday智能体：一个270亿参数的"AI科学家"，能调用代码执行工具，通过假设-验证循环完成复现任务。• 训练后的Faraday展现出真正的科学思维：主动提出假设、系统排查错误、迭代改进，而不是简单复制粘贴代码。 • Replica: A scalable task environment where AI agents must replicate real scientific papers, complete with auto-generated rubric-based scoring that closely matches human judgment. • Faraday: A 27B-parameter AI Scientist agent that uses coding tools to explore, hypothesize, and verify results — trained specifically on replication tasks. • The agent learns a genuinely scientific approach: forming hypotheses, debugging systematically, and iterating — not just blindly copying code.
🧪 实验
内容		 研究团队在多个研究领域的真实科学论文集上训练和评估Faraday。对比基线包括Claude Opus 4.8和GPT-5.5——两个当前最强的前沿AI模型——测试集为模型从未见过的论文复现任务。自动评分裁判的可靠性通过与人类专家评估对比进行了验证。此外，团队还对Faraday的逐步推理过程（"rollouts"）进行了定性分析，以了解它如何处理问题。 The team trained and evaluated Faraday on a collection of real scientific papers spanning multiple research areas. They compared it against strong baselines including Claude Opus 4.8 and GPT-5.5 — two of the most capable frontier AI models available — on held-out replication tasks the model had never seen during training. The auto-generated rubric judge was validated against human assessments to confirm it reliably reflects replication quality. Qualitative analysis of the agent's step-by-step reasoning (called "rollouts") was also conducted to understand how it approaches problems.
📊 实验
结果		 Faraday（270亿参数）在未见过的论文复现任务上超越了Claude Opus 4.8和GPT-5.5。自动评分裁判噪声极低，与人类评估高度一致。定性分析证实，Faraday采用了更具科学原则的假设驱动方法，而不仅仅是生成代码——它像训练有素的研究者一样推理解决问题。 Faraday, at 27B parameters, surpasses both Claude Opus 4.8 and GPT-5.5 on held-out paper replication tasks. The auto-generated rubric judge shows low noise and high agreement with human evaluators. Qualitative analysis confirms that Faraday adopts a more scientifically-principled, hypothesis-driven approach compared to baseline models — not just producing code, but reasoning through problems like a trained researcher.
🏁 结论 本文证明，AI智能体可以通过训练，以科学、系统的方式复现研究论文，并超越更大规模的前沿模型。这为能够进行真正长期科学创新的AI系统奠定了坚实基础。 This paper proves that an AI agent can be trained to replicate scientific research in a principled, hypothesis-driven way, outperforming much larger frontier models. It provides a concrete stepping stone toward AI systems capable of conducting genuine long-horizon scientific discovery.

⚙️ Method · 方法详解

研究团队构建了一个叫Replica的任务框架，每个任务对应一篇真实的科学论文，AI需要复现其核心实验。为了训练AI，他们设计了一个"自动评分裁判"——从论文本身自动生成评分标准，无需人工逐次打分。接着，他们用强化学习对Faraday（基于270亿参数模型）进行后训练，让它反复练习复现任务并从分数中学习改进。Faraday可以调用代码工具：写代码、运行代码、查看输出、再调整——就像真实研究者坐在电脑前工作一样。 The team built a task framework called Replica, where each task is a real scientific paper and the agent must reproduce its key experiments. To train the agent, they needed a way to automatically score how good each replication attempt was, so they designed a rubric-based judge that auto-generates evaluation criteria from the paper itself — no human grading needed for every attempt. They then post-trained Faraday (based on a 27B language model) using reinforcement learning, letting it practice thousands of replication attempts and learn from the scores it received. Faraday uses coding agents as tools, meaning it can write code, run it, see the output, and adjust — just like a real researcher would at a computer.

🌟 Why It Matters · 为什么重要

科学复现是全球研究的一大瓶颈——每年有成千上万篇论文因耗时耗力而无法被验证。能可靠复现实验的AI，可在医学、气候、技术等领域加速知识积累，及时发现错误，推动科学更快前进。 Scientific replication is a global bottleneck — thousands of papers go unverified each year because it takes too much time and expertise. An AI that can reliably replicate experiments could accelerate science across medicine, climate, and technology by catching errors and building knowledge faster.

Synthetic Persona Pretraining: Alignment from Token Zero 合成人格预训练：从第零个Token开始的对齐

🧑‍🔬 Julian Minder, Viktor Moskvoretskii, Raghav Singhal, Difan Jiao et al.

图 Figure · Page 2 of paper

🎯 从预训练第一步就把价值观"烙"进AI，而非事后补丁
Baking human-aligned values into AI from the very first token of pretraining, not as an afterthought.
🗣️ 一句话比喻 · Plain-English Analogy就像培养一个孩子和让一个成年人去上一周道德培训课的区别。传统AI对齐就像那个培训课——价值观教得太晚，很难真正内化。而SPP就像从小把价值观融入孩子读的每一个故事、每一次对话——长大后，诚实善良不是他遵守的规则，而是他本来的样子。Think of it like raising a child vs. sending an adult to a one-week ethics class. Traditional AI alignment is the ethics class — values are taught late and don't always stick. SPP is like raising the child from birth with those values woven into every story, conversation, and lesson — by adulthood, being honest and kind isn't a rule they follow, it's just who they are.
维度 中文 English
❓ 待解决
的问题		 现有的AI助手先用海量文字训练，再在最后阶段"补打"价值观，就像先造好一栋楼再涂油漆——油漆很容易脱落。这导致AI的价值观只是浮在表面，一旦遇到刁钻的提问或特殊情境，它就可能"掉漆"，表现出不符合人类期望的行为，甚至被人恶意绕过（越狱）。 Current AI assistants are trained in two stages: first they absorb massive amounts of raw text (pretraining), and only afterward are values and helpful behavior layered on top. This means good values are like paint on a wall — easy to chip off. The AI can be tricked (jailbroken) into bad behavior, or may quietly hold different values than intended, because those values were never truly baked in from the start.
💡 解决
的亮点		 • 全新范式：不再是训练结束后才"补贴"价值观，而是从第一个token就开始把价值观编织进模型。 • 聪明的数据标注：普通预训练文本被自动添加第一人称道德反思（例如"作为AI，我认为诚实很重要……"），让模型在海量训练中持续接触一致的价值观声音。 • 人格绑定：最后的微调步骤把这个深度嵌入的"人格"与"助手"身份绑定，使对齐行为成为模型的默认本能，而非表面伪装。 • Novel paradigm: Instead of bolting values on after pretraining, SPP weaves a value-aligned "persona" into the model from the very first training step. • Smart annotation trick: Regular text documents are enriched with first-person moral reflections (e.g., "As an AI, I think honesty matters here…") derived from a human value constitution, giving the model a consistent inner voice throughout training. • Persona binding: A final fine-tuning step links this deeply embedded persona to the "assistant" role, making aligned behavior the model's default identity — not a costume it can take off.
🧪 实验
内容		 研究人员训练了最大30亿参数、在5000亿token上训练的模型，对比了三种设置：标准基线（无人格干预）、完整SPP（从第一个token介入）和"晚期SPP"（仅在预训练末尾引入）。评测维度包括：(1) 价值准则遵循度测试；(2) 越狱鲁棒性测试（用对抗性提问试图让模型说坏话）；(3) 分布外道德困境场景（测试价值观能否泛化）；(4) 标准能力基准（确认模型没有变笨）。同时还研究了SPP优势随训练计算量增加而变化的规律。 The researchers pretrained models up to 3 billion parameters on 500 billion tokens, comparing SPP models against standard baselines (no persona intervention) and a "late SPP" variant (persona introduced only at the end of pretraining). They evaluated on: (1) constitution-following benchmarks measuring how well the model obeys its stated principles; (2) jailbreak robustness tests where adversarial prompts try to get the model to misbehave; (3) out-of-distribution moral dilemma scenarios to test whether values generalize beyond training; and (4) standard capability benchmarks to confirm the model didn't get dumber. They also studied how the benefit of SPP scales with pretraining compute budget.
📊 实验
结果		 与标准基线相比，SPP显著提升了价值准则遵循度和越狱鲁棒性。关键发现：从第一个token开始的SPP远胜于预训练末尾才引入的SPP——晚期引入的版本遵循准则更弱、无法改变价值优先级、在道德困境中选择也更不一致。SPP相对于基线的优势随训练算力增加而扩大，说明更大的训练预算会放大对齐收益。更重要的是，这些收益没有牺牲模型在标准基准上的能力表现——SPP模型在通用性能上与基线持平，同时对齐性更好。 SPP significantly improves constitution following and jailbreak robustness over standard baselines. Crucially, SPP from token zero outperforms late-stage SPP introduction: late SPP yields weaker constitution adherence, fails to shift value priorities, and leads to less aligned choices in moral dilemmas. The advantage of SPP over baselines increases with pretraining budget, meaning more compute amplifies the alignment benefit. Importantly, these gains come without sacrificing model capabilities on standard benchmarks — SPP models match baselines on general performance while being more aligned.
🏁 结论 SPP证明了从训练最开始就植入价值观，而非事后补丁，能带来更深层、更稳健的AI对齐效果。这为构建更安全的AI系统确立了一种全新的有效范式：预训练阶段的价值观干预。 SPP proves that embedding values into AI from the very beginning of training — rather than adding them as a post-hoc patch — leads to deeper, more robust alignment. This establishes pretraining-time value intervention as a genuinely effective new paradigm for building safer AI systems.

⚙️ Method · 方法详解

SPP分三步走。第一步，给每篇预训练文档（新闻、书籍等）自动添加第一人称的道德反思短文，就像让AI在读每本书时顺手写下自己的感想日记，这些感想来源于一份人类价值准则。第二步，用这些"原文+反思"组合数据做标准预训练，让价值观思考从第一天就和世界知识一起被吸收。第三步，用普通对话数据做微调，完成"人格绑定"——告诉模型：你在预训练中形成的那个有价值观的声音，就是你作为助手的身份。关键在于要趁早：研究表明，到预训练快结束才引入SPP效果会差很多。 SPP works in three steps. First, each pretraining document (e.g., a news article or book passage) gets annotated with short, first-person moral reflections written from the perspective of a value-aligned AI — like adding a thoughtful diary entry to every piece of text the model reads. These reflections are generated using a value "constitution" (a written set of principles). Second, the model is pretrained on both the original documents and these reflections using the standard training objective, so value-oriented thinking gets embedded alongside world knowledge from day one. Third, after pretraining, the model is fine-tuned on normal user-assistant dialogues. This "persona binding" step tells the model: "That value-aligned voice you developed? That's YOU, the assistant." Early embedding is key — the paper shows that waiting until late pretraining to introduce SPP gives much weaker results.

⚙️ Method · 方法详解

StreamTTT把AI的记忆分成两个独立的"储物格"。一个小本子（短滑动缓存）专门记录最近发生的事情，保持对当前画面的专注；另一个大档案柜（"快速权重"，即在线更新的模型参数）负责存放压缩过的历史信息。两者互不干扰，不争"注意力资源"。模型同时在长视频理解和实时问答两类任务上训练，让它既有长期记忆又有短期敏锐度。 StreamTTT splits the AI's memory into two separate compartments. Think of it like a reporter covering a live event: they jot down quick notes about what's happening right now on a small notepad (the short sliding cache), while older, summarized facts get filed away in a separate notebook (the "fast weights" — model parameters that get updated on the fly as new video comes in). The key insight is that long-range history never competes for space in the short notepad, so the reporter always has sharp eyes on the present moment. The model is then trained on both long videos (to build a good memory) and real-time question-answer scenarios (to stay sharp in the moment).

🌟 Why It Matters · 为什么重要

现实中很多应用场景——比如直播体育解说AI、安防监控助手、实时会议记录系统——都需要持续观看视频、记住历史事件、同时响应当前发生的事，这正是StreamTTT所解决的核心问题。这项研究为构建更聪明的视频AI提供了一条不依赖"堆参数"的实用路径。 Real-world applications like live sports commentary AI, security surveillance assistants, or real-time meeting summarizers all need to watch video continuously, remember past events, and respond to what's happening right now — exactly the problem StreamTTT solves. This work shows a practical path to building smarter, more capable video AI without simply making models bigger and more expensive.
